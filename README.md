# Veteriner Kliniği Randevu ve Hasta Takip Sistemi

- **Öğrenci No:** B241210560
- **Ad Soyad:** Recep Öztürk
- **Ders Grubu:** 1A
- **GitHub:** https://github.com/rcpztrrk/VetKlinik

## Proje Hakkında

Web Programlama dersi proje ödevi. ASP.NET Core MVC ile veteriner kliniği randevu ve hasta takip sistemi geliştiriliyor: klinik hizmetleri, veteriner hekimler, evcil hayvanlar, aşı kayıtları ve randevu yönetimi. Ayrıca sistemin işlevlerini bir yapay zekâ asistanına araç olarak sunan bir MCP sunucusu eklenecek.

## Planlanan Teknolojiler

ASP.NET Core MVC (.NET 10), C#, Entity Framework Core (Code First), LINQ, ASP.NET Core Identity, SQLite, Bootstrap 5, MCP C# SDK.

## Durum

Proje başlangıç aşamasında. Rapor (veritabanı modeli, ekran görüntüleri, REST API uçları, MCP araçları) proje ilerledikçe bu dosyaya eklenecek.
